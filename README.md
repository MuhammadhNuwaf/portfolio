## 🎯 About

Personal cybersecurity portfolio built from scratch — designed to showcase skills, certifications, education, and hands-on lab work. Built with a **cyber-ops terminal aesthetic**: blue/white theme, glitch effects, live threat map, and boot sequence animation.

> Currently pursuing the **BTEC HND in Computing – Cyber Security** at BCAS Campus, Kollupitiya, and the **HTB Junior Cybersecurity Analyst** path.

---

## ⚡ Features

- 🖥️ **Terminal Boot Loader** — animated startup sequence with progress bar
- 💀 **Glitch Text Hero** — animated name reveal
- 📊 **Skill Matrix HUD** — animated proficiency bars
- 🗺️ **Live Threat Map** — canvas-based visualization with attack beams → Colombo
- 📁 **Operations Dossier** — project cards with classified tags
- 🏅 **Certifications Wall** — credential grid
- 🎓 **Education Timeline** — academic journey with status tags
- 📝 **Field Notes** — writeups & learning notes
- 🌐 **Live GitHub Feed** — auto-pulls repos via GitHub API
- 📧 **Working Contact Form** — powered by Formspree
- 📱 **Fully Responsive** — mobile hamburger menu, adaptive layouts
- 📈 **Scroll Progress Bar** + back-to-top button
- 👁️ **Visitor Counter** — live footer badge
- 🔗 **Social Links** — Email · LinkedIn · GitHub · Instagram · Hack The Box

## 🚀 Local Development

### Prerequisites

- **Node.js** 18.17+ ([download](https://nodejs.org))
- **npm** (comes with Node.js) or **pnpm** / **yarn**

### Setup

```bash
# 1. Clone the repo
git clone https://github.com/MuhammadhNuwaf/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
